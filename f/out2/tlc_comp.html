Comprehensive Election Datasets (Compressed Format)

Each compressed (.zip) file contains all available election data reported by the indicated vintage of VTDs. For example, the data from each election included in the 2022 General Election VTD dataset is reported by 2022 general election VTDs.

GIS users can join the election data to the corresponding VTD shapefile available for download from the VTDs collection. Use the common field name 'VTDKEY' to join the data.
